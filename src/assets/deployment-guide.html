Managed SaaS Setup

Estimated time: 5 minutes

Your data is hosted on OptimaX's cloud infrastructure, isolated per tenant. No servers to manage — OptimaX handles updates, backups, and uptime.
Step-by-step
1

Register your business

Go to optimaxsuites.com/get-started and complete the 3-step onboarding: business details → choose your subdomain → create your super-admin account.

2

Verify your email

Click the confirmation link in your inbox. Your tenant is provisioned automatically in under 60 seconds — database schema, default admin, and activated modules.

3

Log in and get to work

Access your ERP at:

https://app.optimaxsuites.com

Use your registered email. Invite your team from Settings → Users.

You're live!

OptimaX handles the rest — updates, backups, SSL, and monitoring.

2

Automatic provisioning

OptimaX automatically:

  • Provisions a dedicated VPS on your selected region
  • Installs and configures the full OptimaX stack

4

Optional: point your own domain

Add a DNS A record at your provider:

TYPE: A
NAME: erp    (or @ for root)
VALUE: {your-instance-ip}
TTL:  300

SSL is issued automatically once DNS propagates (usually 5–30 minutes).

https://erp.yourcompany.com
(or your management URL at acme.optimaxsuites.com)

Self-Hosted Setup

Estimated time: 30–60 minutes on a fresh Ubuntu 22.04 server

Prerequisites

  • Ubuntu 22.04 LTS (or Debian 12) — minimum 4 vCPU, 8 GB RAM, 50 GB SSD
  • Root or sudo SSH access to the server
  • A public IP address (domain name is optional)
  • OptimaX Self-Hosted license (purchased at optimaxsuites.com/pricing)
1

Purchase and get your deploy token

Two ways to purchase:

New customer

Go to optimaxsuites.com/pricing → select Self-Hosted → register & complete checkout → deploy token emailed to you

Existing ERP customer

Log in to ERP → Marketplace → "Deploy Your Own Instance" → choose Self-Hosted → pay → token emailed

Your deploy token looks like:

OPTMX-A3K9X-7BQPZ-MN2WR-9FLKV

Single-use token, valid for 30 days. Keep it private.

2

SSH into your server

ssh root@{your-server-ip}
3

Run the one-click installer

curl -fsSL https://install.optimaxsuites.com/install.sh \
  | bash -s -- \
    --deploy-token=OPTMX-A3K9X-7BQPZ-MN2WR-9FLKV \
    --domain=erp.yourcompany.com

# No domain yet? Use your server IP:
curl -fsSL https://install.optimaxsuites.com/install.sh \
  | bash -s -- \
    --deploy-token=OPTMX-A3K9X-7BQPZ-MN2WR-9FLKV

What the installer does automatically:

  1. Validates your deploy token with OptimaX servers
  2. Retrieves registry credentials and your license key
  3. Installs Docker (if not already present)
  4. Generates a .env file with a secure database password
  5. Creates docker-compose.yml and Caddyfile
  6. Pulls all OptimaX service images from the registry
  7. Starts all services and configures HTTPS automatically

Verify and manage services

6

License renewal

Licenses are annual. Services continue for a 7-day grace period after expiry. To renew:

Purchase a renewal from your account portal → download the new license.key → replace /opt/optimax/license.key → restart services with docker compose restart.

Podman is used on RHEL 9 or corporate Linux environments where Docker isn't available. The installer detects it automatically.
1

Allow Podman to bind port 80

Rootless Podman blocks ports below 1024 by default. Run once:

sudo sysctl -w net.ipv4.ip_unprivileged_port_start=80
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee -a /etc/sysctl.d/99-optimax.conf
2

Run the same installer command

curl -fsSL https://install.optimaxsuites.com/install.sh \
  | bash -s -- \
    --deploy-token=OPTMX-A3K9X-7BQPZ-MN2WR-9FLKV \
    --domain=erp.yourcompany.com

The installer auto-detects Podman and switches to podman compose.

Kubernetes deployment uses the OptimaX Helm chart. Requires Helm 3+ and a running cluster. K3s on a single VM is the simplest option.
1

Get registry credentials

Call the resolve API with your deploy token to get credentials:

curl -X POST https://prod.optimaxsuites.com/api/v2/sub/deploy/resolve \
  -H "Content-Type: application/json" \
  -d '{"deployToken":"OPTMX-A3K9X-..."}'

Response includes registryUser, registryToken, and licenseKey.

2

Create registry secret

kubectl create secret docker-registry optimax-registry \
  --docker-server=registry.gitlab.com \
  --docker-username={registryUser} \
  --docker-password={registryToken}
3

Install via Helm

helm repo add optimax https://charts.optimaxsuites.com
helm repo update
helm install optimax-erp optimax/optimax-erp \
  --namespace optimax --create-namespace \
  --set tenant.id={tenantId} \
  --set license.key={licenseKey} \
  --set domain=erp.yourcompany.com
Common Issues

user-service keeps restarting

Wait 60s for sub-service to seed the tenant database, then: docker compose restart user-service

Permission denied on port 80/443

Rootless Podman only. Fix: sudo sysctl -w net.ipv4.ip_unprivileged_port_start=80

Deploy token "not valid" or "already used"

Tokens are single-use. If you need to re-run the installer, contact support to get a new token issued.

SSL certificate not issued

Port 80 must be open to the internet for Let's Encrypt. Run: ufw allow 80 && ufw allow 443. Then wait 5–30 minutes for DNS to propagate.

License expiry warning

Services continue for 7 days after expiry (offline grace period). Renew at your account portal and replace /opt/optimax/license.key.
